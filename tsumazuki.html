うまくいかないとき

よくあるつまずきと、その直し方です。アプリごとのことは、各アプリのページの「よくある質問」もご覧ください。

設置のとき

setup を実行したら「承認が必要です」と出た

はじめての実行のときは必ず出ます。設置の手順の3のとおりに進んでください。

「Google はこのアプリを確認していません」と出て、先に進めない

左下の小さな 詳細 を押すと、（プロジェクト名）（安全ではないページ）に移動 が出てきます。学校のアカウントでこの文字が出てこないときは、管理者が制限している可能性があります。情報担当の先生にご相談ください。

「関数 setup が見つかりません」「構文エラー」と出る

  • コードが途中までしか貼れていない可能性があります。コードをすべてコピーする でコピーし直し、Ctrl＋A で全部選んでから貼り直してください。
  • はじめから書いてあった function myFunction() { } が残っていないか確かめてください。
  • 貼りつけたあと、保存したか確かめてください。

URLを開くと「ファイルが見つかりません」「index が見つかりません」と出る

HTMLファイルの名前が index になっているか確かめてください。Index や index.html.html では動きません。直したら、新バージョンでデプロイしてください。

開くとき

「申し訳ございません。現在ファイルを開くことができません」と出る

ブラウザで、いくつかのGoogleアカウントに同時にログインしているときによく出ます。次のどれかを試してください。

  • シークレットウィンドウ（プライベートブラウズ）で開く
  • アプリを作ったアカウントだけでログインし直す
  • Chromeなら、アプリを作ったアカウントのプロフィールで開く

生徒の端末で開けない

  • 公開のときの「アクセスできるユーザー」を確かめてください。「（学校名）内の全員」のときは、生徒の端末が学校のアカウントでログインしている必要があります。
  • 「全員」を選べない学校もあります。情報担当の先生にご相談ください。

コードを直したのに、画面が前のまま

保存しただけでは、公開中のアプリは変わりません。デプロイを管理 → 鉛筆 → 新バージョン でデプロイしてください。生徒の端末では、ページを読みこみ直すと新しくなります。

URLが変わってしまった

「新しいデプロイ」を押すと、新しいURLができます。前のURLもそのまま残るので、どちらを使うか決めてください。デプロイを管理 で、使わないほうを アーカイブ すると、まちがえて開くことがなくなります。

使っているとき

たくさんの生徒が一度に開くと、エラーが出ることがある

Googleの決まりで、同時に処理できる数や、1日に使える回数に上限があります。ふつうの授業（1クラス）ではまず問題になりませんが、学年全体で一斉に使うときは、少し時間をずらして開いてもらうと安定します。

スプレッドシートのタブの名前を変えたら動かなくなった

アプリは、タブの名前でデータを探しています。タブの名前は、setup で作られたままにしてください。間違えて消したときは、setup をもう一度実行すると作り直されます（ほかのタブの中身は消えません）。

記録をほかの形で使いたい

記録はスプレッドシートに残っているので、そのまま並べかえたり、グラフにしたりできます。ファイル → ダウンロード から、Excel や CSV でも保存できます。

やめたいとき・消したいとき

デプロイを管理 で公開中のデプロイを アーカイブ すると、URLから開けなくなります。記録もいらないときは、スプレッドシートごと削除してください。
