みんなでグラフ：ドリル

棒グラフ・折れ線グラフを読み取って答える問題を、アプリが自動で作ります。「みんなで」1問ずつ答えたり、「ひとりずつ」自分のレベルで練習したりします。グラフを作るアプリは「みんなでグラフ」です。

何ができるか

進め方ようす
みんなでジャンルを1つ選び、先生が1問ずつ出します。レベルは全員同じか、生徒ごとかを選べます。答えの分かれ方を、先生の画面で見せられます。
ひとりずつ決めた時間、生徒が自分で解きます。ジャンルは1つでも2つでも選べ、レベルは答えぐあいで自動で上下します。
  • 問題を作る必要はありません。毎回ちがうグラフと問題が出ます。
  • 答え方は、4択・2択・記述（数字を入力）から選べます。生徒ごとにも決められます（例：Aさんは2択、Bさんは記述）。いちばんやさしいレベル1は、いつも2択でヒントボタンがつきます。
  • 答えが「いちばん多いのはどれ」「いつからいつ」のように数ではない問題は、記述の生徒にも選ぶ形で出ます。
  • レベルの上限・下限はありません。レベル1〜6のあいだで、つづけて正解・まちがえた数に合わせて自動で上下します（上がる・下がる条件は先生が数字で決めます。生徒ごとに止めることもできます）。
  • まちがえたときは、正解と、まちがいの型に合わせたヒントが出ます。
  • ひとりずつでは、いちばん上のレベル（6）でつづけて20問正解すると「習得」になります（生徒の画面には「習得」とは出しません。先生の画面と記録に残ります）。習得したあとは、ときどき確かめの問題が出たり、タイムアタックで自分の最高記録と比べたり、つぎのジャンルへ進んだりします。
  • 参加のしかたは、名簿から選ぶ・キャラを選ぶ・名前を入れない（「ゲスト1」「ゲスト2」…）から選べます。

設置する

設置の手順のとおりに、次の2つを貼ってください。

このアプリは、このスプレッドシートのほかには、ドライブのファイルにさわりません。setup を実行すると、次のタブができます。

できるタブ中身
名簿1行目に名簿の名前（例：1組）、その下に生徒の名前
生徒設定生徒×ジャンルで1行。出す／出さない、はじめのレベル、自動調整、答え方（4択・2択・記述）、習得したか など
記録1問・1回答ごとの記録
回ごとの記録1回ごと・生徒ごとのまとめ

ジャンルとレベル

ジャンルレベル内容
棒グラフ1〜6表だけを読む（2択・ヒントあり）→ 1目もり1の棒グラフ（項目が少ない）→ 項目がふえる → 多い・少ない・差・合わせた数 → 1目もり2 → 1目もり5
折れ線グラフ1〜61週間の気温などを、表→グラフで読む → 何日・何月とふえる → 「いちばんふえた（へった）のはいつ」→ 目もりが細かくなる

くわしい内容は、先生の画面の 生徒ごとの設定を開く を押すと出る「レベルごとの内容」に、問題の例つきで出ます。

先生の使いかた

先生用のURL（生徒用のURLの最後に ?page=teacher）を開きます。

  1. 「設定」で進め方・ジャンル・答え方・参加のしかたなどを選び、この設定で受付を始める
  2. QRコードが出ます。QRコードを大きく表示 で教室の大きな画面に映す
  3. みんなで：1問目を出す → 答えた人数を見て つぎの問題へ。正解と答えの分かれ方を表示する で答え合わせ。最後は この回を終える
    ひとりずつ：生徒が自分で始めます。進み具合・レベル・習得が一覧で出ます。終えるときは この回を終える
  4. 次の回は、また「設定」から始めます。結果の画面で待っている生徒は自動で入ります

ふだんは出ていない設定（ジャンルの出し方・レベルの自動上下・習得・たまに出す・タイムアタック・印をつける・効果音・生徒画面の文字・生徒の使い方の説明）は、くわしい設定を開く で出ます。

生徒ごとのレベル・答え方・自動調整は 生徒ごとの設定を開く のあとに出る表で決めて、生徒ごとの設定を保存する を押します。

生徒の使いかた

  1. QRコードを読み取る（参加コードが「あり」のときは、4けたの数字を入れる）
  2. 自分の名前（またはキャラ）を選んで 参加する
  3. みんなで：先生が問題を出すまで待つ。ひとりずつ：はじめる を押す

右上の つかいかた で、いつでも説明を見られます。

記録

「記録」タブに1人1問1行で残ります（日時・名前・ジャンル・レベル・問題の型・問題・正しい答え・答え・正誤・まちがいの型・答え方・かかった秒数）。「回ごとの記録」タブには、はじめとおわりのレベル、正答率、多かったまちがい、習得が残ります。

試しに使った記録は、「記録」「回ごとの記録」タブの2行目から下を消してください（1行目の見出しは残します）。

よくある質問

先生用のURLを開いたのに、生徒の画面になる

URLの最後が ?page=teacher になっているか確かめてください。うまくいかないときもご覧ください。

生徒によって、答え方を変えたい

表の「答え方」を押すたびに、先生の設定にしたがう → 4択 → 2択 → 記述と変わります。保存すると、その生徒だけ答え方が変わります。「生徒設定」タブの「答え方」に、4択・2択・記述と書いても同じです（空らんは、受付で選んだ答え方になります）。

記述の生徒に、選ぶ問題が出る

答えが数ではない問題（「いちばん多いのはどれ」「いつからいつ」など）は、文字で書くのがむずかしいため、選ぶ形で出ます。

レベルの上限・下限を決めたい

このアプリには、上限・下限はありません。生徒ごとに「自動調整」を止めると、決めたレベルのまま進みます。
