みんなでマッチング

「仕事をする人」と「使う道具」、「くだものの絵」と「名前」のように、ペアになるものを選ぶ活動です。先生が出した問題に、生徒が自分のiPadで一斉に答えます。

何ができるか

  • 上に出た絵（または文字）とペアになるものを、2〜4つの選択肢から選びます。
  • まちがいの選択肢は、同じタブのほかのペアから自動で選ばれます。問題を作るのは「ペア」だけです。
  • 絵と絵、絵と文字、文字と文字の組み合わせにできます。たとえば問題を絵、選択肢を文字にすると「絵を見て名前を選ぶ」活動になります。
  • ペアの絵は、先生の画面からiPadで撮った写真や画像を選んで登録できます。まとめて登録もできます。
  • こたえを出すと、正解のカードに印がつき、選んだ人数が出ます。最後に一人ひとりの正解数が出ます。
  • 生徒は答えを1回だけ変えられます。制限時間、効果音（あり・なし）も選べます。

設置する

設置の手順にそって、次の2つのファイルを貼ってください。

このアプリの許可について
絵をGoogleドライブに保存するため、setup の許可の画面で「Google ドライブのファイルの表示・作成」などの権限が出ます。絵は、スプレッドシートと同じ場所にできる「みんなでマッチング_がぞう」フォルダにだけ入れます。

setup を実行すると、次のタブとフォルダができます。

できるもの中身
めいぼ（タブ）生徒の名前（例が入っています）
れい（タブ）文字だけの例のペア（りんご→あか など5組）。設置してすぐ試せます。いらなくなったら消してかまいません
タブのせってい（タブ）ペアのタブごとの「分ける・分けない」とAとBの名前
みんなでマッチング_がぞう（ドライブのフォルダ）先生の画面から入れた絵

はじめからある、からっぽの「シート1」は、ペアのタブとまちがえないように setup が消します。ペアのタブ（「しごと」など）は、先生の画面の ペアを作る で作ります。記録のタブは、使うと自動でできます。

このアプリは、「めいぼ」「タブのせってい」「きろく：○○」以外のすべてのタブをペアのタブとして読みます。同じスプレッドシートに、ほかの表を作らないでください。
先生の画面は、スプレッドシートを作ったアカウントでログインしているときだけ開けます。ほかのアカウントで先生用のURLを開くと、生徒の画面になります。

ペアの作り方

先生の画面で作る（おすすめ）

  1. 先生の画面の ペアを作る を押す
  2. 「新しいタブ」に名前（例：しごと）を入れて 作る
  3. AとBに、絵を選ぶか、文字を入れる（どちらか片方だけでもよい）
  4. 登録 を押す。これをペアの数だけくり返す
  • Aだけ、Bだけ入れたものは「ダミー」になり、まちがいの選択肢にだけ使われます。
  • 文字のふりがなは 漢字《かんじ》 と書きます。

まとめて登録する

  1. まとめて登録 → 絵をまとめて選ぶ で、絵をいくつも選ぶ
  2. 選んだ順に A・B・A・B… と並びます。ファイル名が「うんてんしゅ_1」「うんてんしゅ_2」のように1と2で終わるときは、名前でペアにします
  3. まちがっているところは、絵を2つ順に押すと入れかわります
  4. 全部登録 を押す

タブの設定（分ける・分けない）

設定どうなるか例
分けるAが問題なら、選択肢はBの中から出ます。AとBに名前をつけると、生徒の画面に「ペアに なる『どうぐ』は どれかな？」と出ますA＝しごとをする人、B＝どうぐ・ばしょ
分けないAとBに区別がありません同じくだものの2枚の写真

スプレッドシートで直す

ペアのタブは、1行目が Aのえ｜Aのもじ｜Bのえ｜Bのもじ で、1行が1組です。「え」の列には、ドライブの「みんなでマッチング_がぞう」フォルダにある絵のファイル名が入ります。文字を直すときはスプレッドシートで直してかまいません。

先生の使いかた

先生用のURL（生徒用のURLの最後に ?page=teacher）を開きます。

授業の流れ

  1. はじめる を押すと、参加コードとQRコードが出ます
  2. 生徒がそろったら（参加している人の名前が出ます）1もんめを だす
  3. 答えた生徒の名前に ✓ がつきます。こたえ で正解と人数を出す
  4. つぎへ で次の問題へ。最後は けっかを みる で一人ひとりの正解数が出ます

生徒の使いかた

  1. URLかQRコードを開く
  2. （参加コードを使うとき）4けたの数字を入れる
  3. 自分の名前（またはキャラ）を選ぶ
  4. 上の絵とペアになるものを、下から選んで押す。変えるのは1回だけ
  5. 先生がこたえを出すと、正解に「○ せいかい」と出ます

よくある質問

「はじめる」が押せない

そのタブに、AとBがそろったペアが2組以上あるか確かめてください。

絵が出ない（「え が みつからないよ」と出る）

スプレッドシートの「え」の列の名前と、ドライブのフォルダにあるファイル名が同じか確かめてください。
