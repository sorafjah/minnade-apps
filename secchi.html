設置の手順

どのアプリも、この手順で設置します。コードは各アプリのページにあります。

  • 1. スプレッドシートを作る
  • 2. コードを貼る
  • 3. setup を実行する
  • 4. 公開する
  • 5. URLを配る
  • コードを新しくするとき
GoogleのApps Scriptの画面は、ときどき見た目やボタンの名前が変わります。この手順と少しちがっていたら、近い名前のボタンをさがしてください。四角で囲んだ文字は、画面に出ているボタンや項目の名前です。

1. スプレッドシートを作る

  1. パソコンで Googleドライブ を開き、左上の ＋ 新規 → Google スプレッドシート で、新しいスプレッドシートを作る
  2. 左上の「無題のスプレッドシート」をクリックして、名前をつける（例：じぶんのドリル）
  3. 上のメニューの 拡張機能 → Apps Script を選ぶ。新しいタブで、コードを書く画面が開きます
  4. 左上の「無題のプロジェクト」をクリックして、名前をつける（スプレッドシートと同じ名前でかまいません）
アプリ1つにつき、スプレッドシートを1つ作ってください。1つのスプレッドシートに2つのアプリを入れると、うまく動きません。

2. コードを貼る（ファイルは2つ）

Apps Scriptの画面の左側に「ファイル」の一覧があります。ここに次の2つを用意します。

ファイル名種類作り方
コード.gsスクリプトはじめからあります。中に書いてある数行を全部消して、アプリのページの「Code.gs」を貼る
indexHTMLファイルの横の ＋ → HTML を選び、名前に index と入れる（「.html」は自動でつきます）。中身を全部消して、アプリのページの「index.html」を貼る
  1. アプリのページで コードをすべてコピーする を押す
  2. Apps Scriptの画面で、ファイルの中をクリック → Ctrl＋A（Macは ⌘＋A）で全部選ぶ → Ctrl＋V（⌘＋V）で貼る
  3. 2つとも貼れたら、上の保存のマーク（フロッピーディスクの絵）を押す。Ctrl＋S（⌘＋S）でも保存できます
HTMLファイルの名前は index にしてください。ちがう名前だと「ファイルが見つかりません」というエラーになります。

3. setup を1回だけ実行する

コードの上に、次のようなボタンが横に並んでいます。

見た目なにをするもの
▷ 実行選んでいる関数（プログラムのまとまり）を動かすボタン
デバッグ今回は使いません
doGet ▾ など、関数の名前と ▾どの関数を動かすか選ぶところ。はじめは doGet などが出ています
  1. 左のファイルの一覧で コード.gs を押して開く（index.html を開いていると、関数の名前が出てきません）
  2. 関数の名前が出ているところの ▾ を押すと、関数の一覧が出ます。その中から setup を選ぶ
  3. ▷ 実行 を押す
  4. はじめての実行のときだけ、「承認が必要です」という小さな画面が出ます。権限を確認 を押す
  5. アカウントを選ぶ画面が出たら、このスプレッドシートを作ったアカウントを選ぶ
  6. 「Google はこのアプリを確認していません」と出たら、左下の小さな 詳細 を押し、いちばん下の （プロジェクト名）（安全ではないページ）に移動 を押す。
    自分で貼ったコードなので、だれでもこの表示が出ます
  7. 許可の内容が出たら、いちばん下の 許可（または 続行）を押す。チェックをつける欄があるときは、すべてにチェックをつけてから押します
  8. 画面の下に「実行ログ」が出て、「実行完了」と出たら終わりです。スプレッドシートに戻ると、アプリに必要なタブ（「めいぼ」など）ができています
許可の画面に出るのは「このスプレッドシートを見る・編集する」などの権限です。アプリが記録を書きこむために必要なもので、ドライブのほかのファイルにはさわりません。
承認はアカウントごとに1回だけです。2回目からは ▷ 実行 を押すだけで動きます。
ポップアップがブロックされて承認の画面が出ないときは、ブラウザのアドレスバーの右はしに出るマークから「ポップアップを許可」してから、もう一度 ▷ 実行 を押してください。

4. ウェブアプリとして公開する

  1. Apps Scriptの画面の右上の デプロイ → 新しいデプロイ を押す
  2. 「種類の選択」の歯車のマークを押し、ウェブアプリ を選ぶ
  3. 次のように設定する
    項目選ぶもの
    説明空でもかまいません（例：はじめての公開）
    次のユーザーとして実行自分
    アクセスできるユーザー全員：ログインしていない端末からも開けます
    （学校名）内の全員：学校のアカウントでログインしている人だけ開けます
  4. デプロイ を押す。
    ここでも「アクセスを承認」と出ることがあります。そのときは、3の承認と同じように進めてください
  5. 「ウェブアプリ」の下に出てくるURLを コピー する。これが生徒用のURLです
どちらを選ぶか
生徒のiPadが学校のGoogleアカウントでログインしているなら「（学校名）内の全員」が安心です。ログインしていない端末で使うときは「全員」にします。
「全員」にすると、URLを知っている人はだれでも開けます。URLは長くて推測されにくいものですが、学校の外には広めないでください。学校によっては「全員」を選べないように設定されています。

5. URLを配る

だれ用URL
生徒用コピーしたURL（…/exec で終わります）
先生用生徒用のURLの最後に ?page=teacher をつけたもの
例：https://script.google.com/macros/s/（長い文字）/exec?page=teacher

先生用のURLは、ブラウザのブックマークに入れておくと便利です。生徒には、先生画面に出るQRコードを読み取ってもらうのがかんたんです。

コードを新しくするとき（URLを変えない方法）

このサイトでアプリが新しくなったときや、自分でコードを直したときは、次の手順で入れかえます。この方法なら、生徒用のURLは変わりません。

  1. 新しいコードを、コード.gs と index に貼りかえて保存する
  2. 右上の デプロイ → デプロイを管理 を押す
  3. 右上の鉛筆のマーク（編集）を押す
  4. 「バージョン」で 新バージョン を選ぶ
  5. デプロイ を押す
ここで「新しいデプロイ」を選ぶと、URLが新しくなります。前のURLやQRコードはそのまま古い中身で動き続けるので、まちがえやすくなります。

コードを新しくしても、スプレッドシートの名簿や記録はそのまま残ります。新しいタブや見出しが必要なときは、アプリが自動で足します。
