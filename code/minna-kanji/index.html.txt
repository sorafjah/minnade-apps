var COMMON = 'あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろわんがぎぐげござじずぜぞだでどばびぶべぼ'.split('');
function nearOf(c) { var out = []; PAIRS.forEach(function (p) { if (p.indexOf(c) >= 0) p.split('').forEach(function (x) { if (x !== c && out.indexOf(x) < 0) out.push(x); }); }); return out; }
function makeTiles(r) {
  var chars = r.split(''), n = Math.min(6, Math.max(3, Math.ceil(chars.length * 0.6))), d = [], near = [];
  chars.forEach(function (c) { nearOf(c).forEach(function (x) { if (chars.indexOf(x) < 0 && near.indexOf(x) < 0) near.push(x); }); });
  shuffle(near).forEach(function (c) { if (d.length < Math.ceil(n / 2)) d.push(c); });
  var rest = shuffle(COMMON.filter(function (c) { return chars.indexOf(c) < 0 && d.indexOf(c) < 0; }));
  while (d.length < n && rest.length) d.push(rest.pop());
  return shuffle(chars.concat(d)).map(function (c, i) { return { c: c, id: i, used: false }; });
}

function setupSelf(rd, conf) {
  var saved = me.selfState && me.selfState.rid === rd.id ? me.selfState : null;
  var lo = conf.lower || 1, up = conf.upper || MAX_LV;
  if (lo > up) { var t = lo; lo = up; up = t; }
  var start = Math.max(lo, Math.min(up, conf.level || conf.last || rd.level || 1));
  D = {
    level: start, start: start, min: lo, max: up, auto: rd.autoLv && conf.auto !== false,
    okRun: 0, ngRun: 0, lowNg: 0, types: {}, count: 0, correct: 0, miss: [],
    endAt: 0, timeUp: false, ended: false, finished: false, pool: {}, used: {}, fetching: {}
  };
  // 画面を読みこみ直したときは、それまでの解いた数・レベルなどをもどす
  if (saved) ['level', 'start', 'okRun', 'ngRun', 'lowNg', 'types', 'count', 'correct', 'miss', 'endAt', 'used'].forEach(function (f) { if (saved[f] !== undefined) D[f] = saved[f]; });
  D.level = Math.max(lo, Math.min(up, D.level));
}

// そのレベルのことばを、サーバーからもらう
function fetchWords(lv) {
  if (D.fetching[lv]) return D.fetching[lv];
  var d = D;
  d.fetching[lv] = api('api_words', me.roundId, lv, 40).then(function (list) {
    var p = d.pool[lv] || (d.pool[lv] = []), have = {};
    p.forEach(function (w) { have[w[0]] = 1; });
    (list || []).forEach(function (w) { if (!have[w[0]]) { have[w[0]] = 1; p.push(w); } });
    setNet(true);
  }).catch(function () { setNet(false); }).then(function () { d.fetching[lv] = null; });
  return d.fetching[lv];
}
function unusedOf(lv) { return (D.pool[lv] || []).filter(function (w) { return !D.used[w[0]]; }); }
function takeWord(lv) {
  var c = unusedOf(lv);
  if (!c.length) c = (D.pool[lv] || []).filter(function (w) { return !ST.q || w[0] !== ST.q[0]; });
  if (!c.length) c = D.pool[lv] || [];
  if (!c.length) {   // つながらないときは、手もとにある近いレベルのことばを出す
    var ks = Object.keys(D.pool).filter(function (k) { return D.pool[k].length; }).sort(function (a, b) { return Math.abs(a - lv) - Math.abs(b - lv); });
    if (ks.length) c = D.pool[ks[0]];
  }
  if (!c.length) return null;
  var w = c[Math.floor(Math.random() * c.length)];
  D.used[w[0]] = 1;
  return w;
}
function prefetch() {
  var lv = D.level;
  if (unusedOf(lv).length < 5) fetchWords(lv);
  if (D.auto) {
    if (lv < D.max && !D.pool[lv + 1]) fetchWords(lv + 1);
    if (lv > D.min && !D.pool[lv - 1]) fetchWords(lv - 1);
  }
}

function startSelf() {
  if (!D.endAt) D.endAt = Date.now() + ST.round.minutes * 60000;
  saveSelf();
  clearInterval(clockTimer); clockTimer = setInterval(tickSelf, 250);
  sendSnap();
  nextSelf();

function tickSelf() {
  if (!D || D.finished) return;
  var left = Math.max(0, Math.ceil((D.endAt - Date.now()) / 1000));
  var txt = 'のこり ' + (left >= 60 ? Math.floor(left / 60) + '分' + (left % 60 ? (left % 60) + '秒' : '') : left + '秒');
  if (ST.view === 'quiz' && txt !== lastShown) { lastShown = txt; var el = swap('timer', txt); el.classList.remove('hidden'); }
  if (left <= 0 && !D.timeUp) {
    D.timeUp = true;
    if (ST.view !== 'quiz') { finishSelf(); return; }
    if (ST.answered) { var nb = $('nextBtn'); if (nb) nb.innerHTML = R('おわる'); }
    else banner('じかんに なったよ。<br>この もんだいで おわりだよ', 2200);
  }
}
function nextSelf() {
  if (!D || D.finished) return;
  if (D.timeUp || D.ended) { finishSelf(); return; }
  var w = takeWord(D.level);
  if (w) { prefetch(); showQuestion(w); return; }
  // まだ ことばが とどいていないとき
  var d = D;
  if (ST.view !== 'quiz') { $('readyGoRow').classList.add('hidden'); $('readyDots').classList.remove('hidden'); }
  fetchWords(D.level).then(function () {
    if (D !== d || d.finished) return;
    var w2 = takeWord(d.level);
    if (w2) { prefetch(); showQuestion(w2); }
    else setTimeout(function () { if (D === d && !d.finished) nextSelf(); }, 3000);
  });
}
function afterSelf(ok, type, pick) {
  var q = ST.q, rd = ST.round;
  D.count++;
  if (ok) D.correct++;
  else { D.types[type] = (D.types[type] || 0) + 1; if (D.miss.length < 40) D.miss.push([q[0], q[1]]); }
  outPush({
    id: uid(), kind: 'answer', at: Date.now(), roundId: me.roundId, name: me.name, mode: 'self', level: q[3],
    q: q[0], correct: q[1], pick: pick, ok: ok, ml: ok ? '' : type, how: ST.how, sec: Math.round((Date.now() - ST.qStart) / 1000)
  });
  // その生徒のいちばん下のレベルで、まちがいがつづいている
  if (D.level === D.min) D.lowNg = ok ? 0 : D.lowNg + 1; else D.lowNg = 0;
  // レベルの自動上下（変わっても何も表示しない）
  if (ok) { D.okRun++; D.ngRun = 0; } else { D.ngRun++; D.okRun = 0; }

    if (D.okRun >= rd.up && D.level < D.max) { D.level++; D.okRun = 0; }
    else if (D.ngRun >= rd.down && D.level > D.min) { D.level--; D.ngRun = 0; }
  }
  saveSelf();
  sendSnap();
  flushOutbox();
}
function topType(types) {
  var top = '', tn = 0;
  Object.keys(types).forEach(function (t) { if (types[t] > tn) { top = t; tn = types[t]; } });
  return { t: top, n: tn };
}

    remain: D.endAt ? Math.max(0, Math.round((D.endAt - Date.now()) / 1000)) : null, top: topType(D.types).t, flag: D.lowNg >= ST.round.flagN
  } });
}

    setTimeout(function () { if (btn.isConnected) { btn.dataset.sure = ''; btn.textContent = label; } }, 5000);
    return;
  }
  btn.disabled = true;
  var p = act === 'next' ? api('api_tSetQ', r.id, r.curQ + 1) : api('api_tEnd', r.id);
  p.then(function (x) { T.round = x; T.reveal = false; T.qView = act === 'next'; setNetT(true); }).catch(function () { setNetT(false); }).then(tPoll);
}
function lvChange(a, b) { a = +a; b = +b; if (!a || !b || a === b) return String(b || a || ''); return a + '→<span class="' + (b > a ? 'lvup' : 'lvdn') + '">' + b + '</span>'; }
function netCell(r, m) {
  if (r.status !== 'open') return '';
  if (m.ago < 0) return '<span class="subc">—</span>';
  return m.ago <= 30 ? 'つながっている' : '<span class="ngc">' + (m.ago < 120 ? m.ago + '秒前まで' : 'つながっていない') + '</span>';
}

function renderTQ() {
  var r = T.round, s = r.settings, on = r.status === 'open' && s.mode === 'all' && r.curQ >= 0;
  if (!on) T.qView = false;
  $('qCard').classList.toggle('hidden', !(on && T.qView));
  if (!on || !T.qView) return;
  var keys = (r.sets || []).filter(function (k) { return T.sets[k]; });
  if (!keys.length) return;
  if (!T.sets[T.viewKey]) T.viewKey = keys[0];
  $('tLvTabs').innerHTML = keys.length > 1 ? keys.map(function (k) { return '<button class="gchip' + (k === T.viewKey ? ' on' : '') + '" data-k="' + k + '">レベル' + k + 'の問題</button>'; }).join('') : '';
  $('tLvTabs').querySelectorAll('[data-k]').forEach(function (b) { b.addEventListener('click', function () { T.viewKey = b.dataset.k; renderTQ(); }); });
  var q = T.sets[T.viewKey][r.curQ];
  if (!q) return;
  swap('tqTitle', (r.curQ + 1) + '問目（' + lvText(q[3]) + '）');
  swap('tqState', '全部で ' + s.count + '問');
  swap('tqWord', esc(q[0]));
  var rv = T.reveal, cnt = {};
  T.members.filter(function (m) { return String(m.lv) === String(T.viewKey); }).forEach(function (m) { var a = m.ans && m.ans[r.curQ]; if (a) { var k = a[3] || '（答えなかった）'; cnt[k] = cnt[k] || { n: 0, ok: a[1] }; cnt[k].n++; } });
  $('revealBtn').textContent = rv ? '正解と答えの分かれ方をかくす' : '正解と答えの分かれ方を表示する';

  swap('tqDist', rv ? (Object.keys(cnt).sort(function (a, b) { return cnt[b].n - cnt[a].n; }).map(function (k) { return '<span class="' + (cnt[k].ok ? 'c' : '') + '">' + esc(k) + '：' + cnt[k].n + '人' + (cnt[k].ok ? '・正解' : '') + '</span>'; }).join('') || '<span>まだ答えた人はいません</span>') : '');

function whoMode() { try { return localStorage.getItem('minna-kanjiyomi-who') === 'count' ? 'count' : 'name'; } catch (e) { return T.who || 'name'; } }

function renderWho(r) {
